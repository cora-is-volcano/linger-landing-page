How it works

Your local setup. With a local server and model, Linger stores its workspace and memory on your computer and runs inference there. You choose connected apps; agents use the file and tool permissions of their runtime.

Two kinds of memory. Your shared personal wiki is searchable by all your agents. Each agent also keeps a separate memory of its own conversations, preferences and lessons.

From context to work. Your agents can use tools, run tasks and coordinate in Rooms, bringing the relevant context into the work.

Local mode does not mean every connection is offline. Connected apps, voice, and background work using a remote model can send data to external services.

Test conditions

Median of three runs: Intel Core i7-12700, 64 GB DDR4-3200, Windows 11 and Strata 0.1.41. A 4,096-token prompt, 256 generated tokens, INT8 KV cache, temperature 0 and multi-token prediction enabled; loading and warm-up excluded. Performance varies with hardware, model and workload.

Your choice of models

PolyStrata supports 12 models, including Qwen, DeepSeek and Gemma. Model and platform support varies; the 11 models on PolyStrata’s own engine are experimental. Quick Install recommends a model that fits your hardware.

Common questions.

Browse the docs
Is Linger an app or a platform?

Both. The desktop app is the easiest way to start; underneath is an open-source framework for personal agent teams. Use agent teams, proactive follow-ups, voice and meetings, browser and desktop tools, and custom skills. Capabilities vary by platform; voice and connected apps use external services.

What stays on my computer?

With a local server and model, your data and memories are stored on your computer and inference runs there. Connected apps, voice and some background memory workflows use external services. Cloud models send requests to the provider you choose. See the data and privacy guide.

Does local AI have a per-token cost?

Local inference runs on your hardware without per-token cloud API fees. If you choose a cloud model or connect a paid service, that provider’s pricing still applies.

Which computers can run Linger?

The desktop app runs on Apple silicon Macs, Windows x64 and Linux x64 with glibc 2.35 or later. Intel Mac users can use Docker Compose. Local model support depends on your hardware and available memory.

How does a larger model fit on a PC?

For supported mixture-of-experts models, PolyStrata keeps frequently used parts of the model in GPU memory and places others in system memory or on disk. Read about local inference.

Can several agents work on one task?

Yes. A Room brings agents together around a shared team.md plan, with defined roles and handoffs. Choose supported runtimes such as Claude Code, Codex or Pi; cloud runtimes use their own services. Explore agent teams.

Can I build on Linger?

Yes. Add skills, configure tools and connect supported runtimes to fit your workflows. Start with the skill development guide or explore the platform architecture.
