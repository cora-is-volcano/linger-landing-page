How can I try Linger?

The open-source app on GitHub runs on macOS, Windows and Linux. For hosted access, join the tester waitlist.

Does everything stay on my computer?

Your files, memory and knowledge base stay on your computer. Local models run on-device; cloud models and connected services use external providers. Voice requires provider setup: Soniox for meetings and xAI for live conversation.

Data & privacy
What do I need to get started?

Install Linger, then connect a runtime and a local or cloud model. Local models require compatible hardware.

Setup guide
Can I use my existing AI subscription?

You can use supported providers through Claude Code, Codex or Pi. Your provider’s policies, usage limits and charges apply.
